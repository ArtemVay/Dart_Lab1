# Как запустить  
1. Клонировать репозиторий: `git clone https://github.com/ArtemVay/Dart_Lab1.git`
2. Перейти в папку: `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

# Ответы на вопросы:  
1. В Dart типы проверяются сразу на этапе компиляции, а в Python только во время выполнения, из-за чего ошибки будут видны только в конце, в отличие от первого языка
2. String? это переменная с возможным значением null, а просто String это только строка
3. final не даёт перезаписать значение переменной, чтобы сразу увидеть ошибку в случае чего, в отличие от Python
4. Именованный передаётся по имени, а позиционный по порядку, пример:
```dart
describePet(name: "Барсик", age: 3);
```
